# Goals + Ekagra Refined Guide

Simple step-by-step guide in Hinglish.

## 1) Goals System: Quick Start

### Step 1: Goal Create karo
1. Goals page kholo.
2. Add Goal button dabao.
3. Title me clear kaam likho.

Example:
- Physics ke 20 numericals
- Revision of Chapter 3

### Step 2: Goal Type choose karo
1. Today: sirf aaj ke liye.
2. One-time: deadline optional, complete hone tak rahega.
3. Repeat: regular habit style goal.

### Step 3: Tracking Method choose karo
1. Done / Not done: simple completion tracking.
2. By number (count): quantity-based tracking.
3. Track by focused time: minutes-based tracking.
4. Checklist points: step-by-step tracking.

### Step 4: Target set karo
1. Number mode me target count do.
2. Time mode me target minutes do.
3. Checklist mode me subtask points add karo.

### Step 5: Optional settings (advanced)
1. Carry forward mode set kar sakte ho.
2. Start time (IST) de sakte ho.
3. Existing progress (already started) add kar sakte ho.
4. Execution status set kar sakte ho (edit mode).

### Step 6: Save aur track
1. Create Goal dabao.
2. Goals tab me pending goals dikhte hain.
3. Complete karte hi analytics auto-update hota hai.

---

## 2) Ekagra System: Quick Start

### Step 1: Goal link ya manual task
1. Goals page se Start Focus use kar sakte ho.
2. Ya Ekagra page me manual task create kar sakte ho.

### Step 2: Timer setup
1. Timer duration select karo.
2. Break duration bhi set karo (short/long).
3. Optional: custom minutes input use karo.

### Step 3: Session run karo
1. Play dabao to session start hoga.
2. Pause kar sakte ho agar break chahiye.
3. Resume se same session continue hota hai.

### Step 4: Session control
1. Session overlay se switch/pause/complete/discard manage karo.
2. Active linked goal UI me dikhai dega.
3. Session history me old sessions track hote rehte hain.

### Step 5: Completion flow
1. Timer complete hone par linked task completion flow trigger hota hai.
2. Next task duration choose karke continue kar sakte ho.
3. Agar sab done ho gaya, naya task add karo.

---

## 3) Analytics Samajhne ka easy tareeka

### Goals Analytics
1. Completion Rate: completed manual goals / total manual goals.
2. Average Progress: active + completed manual goals ka avg progress.
3. Consistency (7 Days): 7 din me kitne din at least 1 completion hui.
4. Current Streak: consecutive completion days.
5. Goal Consistency Trend: last 7 days ka completion percentage trend.

### Live Pulse
1. Aaj complete hue manual goals ka count.
2. Aaj ka total lifecycle duration.
3. Aaj ka avg completion time.
4. Daily progress bar (target baseline ke against).

---

## 4) Best Practices (Recommended)

1. Goal title short aur action-oriented rakho.
2. Bade goal ko checklist me break karo.
3. Time-based goals ke liye linked focus sessions ON rakho.
4. Har session ke baad quick review karo: continue, pause, ya complete.
5. Daily analytics dekh ke next day ka realistic plan banao.

---

## 5) Common Confusions

### Q1: Dummy data dikh raha hai kya?
- Nahi, mostly account-linked API data aata hai.
- Agar network fail ho, kuch sections fallback zero dikhate hain.

### Q2: Goal aur Ekagra same cheez hai?
- Nahi.
- Goal = plan.
- Ekagra session = focused execution timeline.

### Q3: Time-based goal me kya must hai?
- Target minutes set hona chahiye.
- Linked focus enable karoge to tracking smooth hoti hai.

---

## 6) One-Minute Setup Flow

1. Add Goal -> type and target set karo.
2. Start Focus -> timer run karo.
3. Session complete -> goal progress update.
4. Analytics check -> next action decide.
