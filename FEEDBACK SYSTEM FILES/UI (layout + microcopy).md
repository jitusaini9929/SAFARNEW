🧠 6. DESIGN STYLE GUIDELINES
=============================

🎨 Visual Style
---------------

*   Dark theme match (your current UI)
    
*   Soft rounded corners
    
*   Slight glow on focus
    
*   Smooth fade-in animation
    

⚡ Interaction Rules
-------------------

*   Open in **modal OR slide-up panel**
    
*   Do NOT navigate away
    
*   Keep it interrupt-free
    

⚖️ 7. SIMPLICITY LEVEL
======================

✅ Ideal:
--------

*   1 tap → open
    
*   1 tap → start typing
    
*   1 tap → submit
    

👉 Total time: **<10 seconds**

❌ Avoid:
--------

*   Required fields
    
*   Long forms
    
*   Multi-step flows beyond 2 steps
